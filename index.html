KCC Mesh · the compute-economy rail

Idle rigs stop mining wasted hashes and become sovereign mesh-nodes that earn internal contribution-units by verified work: a bounty is escrowed, a node claims it and does the compute, and it is paid only if the result re-verifies (proof-of-contribution, not proof-of-asking). Units are conserved — no minting after genesis — on a tamper-evident chain, and each node has a budget ceiling it cannot cross, so no node can drain the mesh.

⚠ Internal contribution-units — NOT money. These are not a currency, not a cryptocurrency, not tradeable. There is no code path from a unit to money: this kernel exposes no fiat / trade / exchange / withdraw / sell / convert verb (a test checks that against the code). The money rail is a separate, gated matter behind legal counsel.
